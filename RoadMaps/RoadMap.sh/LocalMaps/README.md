# 🗺️ Roadmap Viewer — локальный просмотрщик дорожных карт roadmap.sh

Интерактивный одностраничный просмотрщик дорожных карт с сайта [roadmap.sh](https://roadmap.sh). Работает **полностью локально**, без интернета и внешних зависимостей. Позволяет отмечать пройденные шаги, вести заметки, настраивать шрифт для каждого типа блоков, сохранять прогресс по картам и переключать тему оформления.

---

## ✨ Возможности

### Основное
- **Автономная работа** — никаких CDN, фреймворков и сетевых запросов, кроме загрузки JSON-файлов карт.
- **Загрузка карт** тремя способами: из локальной папки `roadmaps/`, по URL (например `https://roadmap.sh/redis.json`) или перетаскиванием JSON прямо в окно.
- **Масштабирование и панорамирование** — колесо мыши, перетаскивание, двойной клик — «вписать карту в экран».
- **Все элементы дорожной карты** отрисовываются корректно: узлы, связи, типы блоков.

### Прогресс и состояния узлов
- **Три состояния узла**:
  - `✓` — пройдено (серый фон, зачёркнутый текст, связь к потомкам становится зелёной),
  - `⏳` — изучаю сейчас (янтарный фон с пунктирной рамкой),
  - по умолчанию — не пройдено.
- **Отметка кликом** по блоку или по кнопке `✓`.
- **Счётчик прогресса** в правом верхнем углу: `Пройдено: N / M · изучаю: K`.
- **Прогресс сохраняется отдельно для каждой карты** в `localStorage`.

### Заметки
- К каждому узлу можно привязать **заметку** — кнопка `📝` в правом верхнем углу блока.
- Если заметка есть, кнопка подсвечивается.
- Модальное окно с текстовым полем, счётчиком символов и горячими клавишами: `Ctrl+Enter` — сохранить, `Esc` — закрыть.
- Заметки сохраняются отдельно для каждой карты.

### Чеклисты с подпунктами
- Узлы типа `checklist` с массивом `data.checklists` отображаются **списком подпунктов**.
- Каждый подпункт — настоящий SVG-чекбокс, состояние которого сохраняется в `localStorage`.
- Когда **отмечены все подпункты**, узел автоматически становится «пройденным» (серый фон, зачёркнутый заголовок, зелёная кнопка `✓`). Если снять любой — «пройдено» снимается.
- Кнопка `✓` на таком узле работает как «отметить/снять все».

### Иконки типов и стилизация
- У каждого типа блока — своя **иконка и цветовая схема**: `◆` topic, `●` subtopic, `■` section, `★` title, `¶` paragraph, `▸` button.
- Отдельная цветовая схема для `checklist` — янтарная.

### Настройка шрифта
- **Свой стиль для каждого типа узлов** — размер (6–40 px), цвет, гарнитура.
- Панель `⚙️ Настройки` в правом нижнем углу.
- Все настройки сохраняются в `localStorage`.
- Кнопки сброса: для конкретного типа или для всего сразу.

### Переключатель темы
- Три темы: **светлая** ☀️, **тёмная** 🌙, **неон** ✨ (с эффектами свечения).
- Переключение через панель настроек.
- Выбор сохраняется между сессиями.

### Быстрое меню карт
- `📚 Карты` в левом верхнем углу.
- **По умолчанию свёрнуто** — раскрывается по клику на заголовок.
- **Автоматически сворачивается после выбора карты.**
- Поиск по названию карт.
- Группировка по типу: `🎯 Роли`, `🛠️ Технологии`, `✅ Best Practices`, `📦 Прочее` (если в `manifest.json` указано поле `type`).
- Кнопка `📁 Выбрать JSON-файл…` внизу панели.
- Блок `🔗 Связанные` — чипы связанных карт из поля `relatedRoadmaps`.

### Панель «О карте» и «Справка»
- Плавающие кнопки `ℹ️` и `?` в правом верхнем углу (или горячие клавиши `I` и `?`).
- **ℹ️ О карте**: описание, дата обновления, связанные карты, список курсов с чекбоксами, список вопросов, ключевые темы, ссылка на оригинал на roadmap.sh.
- **❓ Справка**: главный вопрос карты (`type: main`) в выделенном блоке + аккордеон с FAQ (`type: faq`).
- **Ссылки внутри FAQ ведут к узлам карты**: клик по ссылке вида `roadmap.sh/ai-engineer/observability-tools` плавно подъезжает к нужному узлу и подсвечивает его.

### Кнопки у каждого блока
- `🔍` — поиск в Google. Запрос формируется умно: если из `seo.keywords` находится фраза с хорошим совпадением — берётся она, иначе — название карты. Формат: `<префикс>: <текст блока>`.
- `📝` — заметка.
- `⏳` — «изучаю сейчас».
- `✓` — «пройдено».
- `?` — быстрый переход к связанному FAQ (если найден по совпадению слов ≥ 2).

### Горячие клавиши
- `?` — открыть/закрыть справку.
- `I` (или `Ш`) — открыть/закрыть панель «О карте».
- `Esc` — закрыть панель/модальное окно.
- `Ctrl+Enter` — сохранить заметку.
- `Двойной клик` — вписать карту в экран.

### Умная раскладка блоков
- Стартовое положение блоков берётся из `position` (или `positionAbsolute`, если `position` нет).
- **Расталкивание перекрытий**: 80 итераций, 16 px зазора + запас под кнопки — блоки гарантированно не пересекаются.
- **При изменении шрифта** размеры и позиции пересчитываются автоматически — блоки двигаются, чтобы не пересекаться.
- **Перенос текста** — блок сначала пробует уместить текст переносом строк, и только если не влезает — растёт.

## 🚀 Быстрый старт

### 1. Скачайте или склонируйте файлы

Создайте папку и положите туда `index.html` и `create-roadmaps.bat`.

### 2. Создайте папку `roadmaps` со списком карт

Двойной клик по **`create-roadmaps.bat`** — рядом появится папка `roadmaps/` с пустыми JSON-файлами и `manifest.json`.

> Если Windows блокирует запуск `.bat`: правой кнопкой → «Свойства» → «Разблокировать», либо запустите от имени администратора.

### 3. Заполните JSON-файлы данными

Откройте любую карту с roadmap.sh и сохраните её JSON по адресу `https://roadmap.sh/<slug>.json`.

**Примеры прямых ссылок:**

| Карта | JSON URL |
|---|---|
| Machine Learning | `https://roadmap.sh/machine-learning.json` |
| Software Architect | `https://roadmap.sh/software-architect.json` |
| PostgreSQL DBA | `https://roadmap.sh/postgresql-dba.json` |
| Redis | `https://roadmap.sh/redis.json` |
| MongoDB | `https://roadmap.sh/mongodb.json` |
| Elasticsearch | `https://roadmap.sh/elasticsearch.json` |
| TypeScript | `https://roadmap.sh/typescript.json` |
| Python | `https://roadmap.sh/python.json` |
| SQL | `https://roadmap.sh/sql.json` |
| AWS | `https://roadmap.sh/aws.json` |
| Backend | `https://roadmap.sh/backend.json` |
| AI Engineer | `https://roadmap.sh/ai-engineer.json` |
| Code Review | `https://roadmap.sh/code-review-best-practices.json` |
| API Security | `https://roadmap.sh/api-security-best-practices.json` |
| Frontend Performance | `https://roadmap.sh/frontend-performance-best-practices.json` |
| Backend Performance | `https://roadmap.sh/backend-performance-best-practices.json` |

**Быстрый способ** — используйте `download-roadmaps.bat`, если он есть: он скачает JSON для всех стандартных карт через `curl`.

> ⚠️ Кастомные ИИ-карты (например `c-sharp-he09r` или `ml-engineer-3dqvu`) **не имеют публичного JSON** — они генерируются динамически. Для таких карт можно скрапить HTML или создавать JSON вручную.

### 4. Запустите локальный сервер

Из-за политики CORS браузер не позволит прочитать `manifest.json` через `file://`. Запустите любой локальный HTTP-сервер из папки с `index.html`:

**Python 3:**
```bash
python -m http.server 8000
```

**Node.js:**
```bash
npx serve
```

**PHP:**
```bash
php -S localhost:8000
```

### 5. Откройте в браузере

```
http://localhost:8000/index.html
```

Слева сверху появится **свёрнутое** меню `📚 Карты` — разверните его и выберите карту. Или вставьте URL JSON прямо в поле на стартовом экране. Или перетащите JSON-файл в окно.

## ⚙️ Настройки

### Шрифт
В панели `⚙️ Настройки` выберите **тип блока** (`topic`, `subtopic`, `section`, `checklist`, `title`, `paragraph`, `button`, `default`) и задайте для него:
- **Размер** — от 6 до 40 px.
- **Цвет** — любой через color picker.
- **Шрифт** — системный, Inter, Arial, Georgia, Consolas и другие.

При увеличении шрифта блок сначала пытается уместить текст переносом строк, и только если не помогает — растёт. Остальные блоки автоматически сдвигаются, чтобы избежать перекрытий.

### Тема
- ☀️ **Светлая** — пастельные тона, мягкие тени.
- 🌙 **Тёмная** — глубокий тёмно-синий фон, светлые карточки.
- ✨ **Неон** — почти чёрный фон, светящиеся пурпурные и голубые границы.

Выбор темы сохраняется между сессиями.

## 💾 Хранение данных

Все данные хранятся **только в вашем браузере** через `localStorage`. Ключи имеют вид `roadmap-<тип>-v1::<имя-карты>.json`:

| Ключ | Что хранит |
|---|---|
| `roadmap-progress-v1::<карта>` | Пройденные узлы |
| `roadmap-learning-v1::<карта>` | Узлы «изучаю сейчас» |
| `roadmap-notes-v1::<карта>` | Заметки к узлам |
| `roadmap-checklist-items-v1::<карта>` | Отметки подпунктов чеклистов |
| `roadmap-courses-v1::<карта>` | Отметки курсов |
| `roadmap-font-settings-v2` | Настройки шрифта (общие для всех карт) |
| `roadmap-theme-v1` | Выбранная тема |

Чтобы сбросить всё — очистите данные сайта в DevTools → Application → Local Storage, либо используйте кнопки сброса в интерфейсе.

### 💡 Как переносить состояние между браузерами

1. В браузере **А** нажмите `💾 Выгрузить состояние` — скачается JSON-файл.
2. Перенесите файл в браузер **Б** (или на другое устройство) любым удобным способом.
3. В браузере **Б** откройте просмотрщик, разверните `⚙️ Настройки`, нажмите `📥 Загрузить состояние`, выберите файл.
4. Подтвердите перезагрузку — весь прогресс, заметки, чеклисты, шрифты и тема будут восстановлены.

### 🔒 Заметки

- Данные из `localStorage` **не покидают браузер** — файл скачивается локально, никаких сетевых запросов.
- Импорт безопасен: пишутся только ключи с префиксом `roadmap-`, остальное в `localStorage` не трогается.
- Файл можно держать как бэкап — им удобно откатить состояние, если случайно сбросили прогресс.

## 📁 Формат JSON

Просмотрщик работает с JSON-файлами от roadmap.sh. Ключевые поля:

- **`title.card` / `title.page`** — название карты (идёт в заголовок вкладки, Google-запрос и панель «О карте»).
- **`description`** — короткое описание.
- **`slug`** — URL-часть, используется для ссылки на оригинал.
- **`nodes[]`** — массив узлов. У каждого:
  - `id`, `type` (`topic`, `subtopic`, `section`, `checklist`, `title`, `paragraph`, `button`, `label`, `horizontal`, `vertical`),
  - `position` (относительные координаты, используется по умолчанию) и `positionAbsolute` (абсолютные координаты, fallback),
  - `data.label` — текст,
  - `data.checklists` — массив подпунктов для типа `checklist`,
  - `measured` / `width` / `height` — размеры.
- **`edges[]`** — связи между узлами (`source` → `target`).
- **`questions[]`** — вопросы `type: main` и `type: faq` в формате Tiptap.
- **`relatedRoadmaps[]`** — массив slug'ов связанных карт.
- **`seo`** — `title`, `description`, `keywords[]`.
- **`courses`** / **`aiCourses`** — названия рекомендованных курсов.
- **`type`** — тип карты (`role`, `skill`, `best-practices`), используется для группировки в меню.

## ❓ Частые вопросы

**Меню `📚 Карты` пишет «manifest.json не найден».**
Откройте страницу **через локальный сервер** (`http://localhost:8000/...`), а не двойным кликом по `index.html`. Или убедитесь, что `create-roadmaps.bat` был запущен и `roadmaps/manifest.json` существует.

**Карта пустая, хотя JSON скачан.**
Проверьте, что в JSON есть `nodes` с координатами и непустым `data.label`. Служебные узлы (`horizontal node`, `vertical node`, пустые `section`) отфильтровываются автоматически.

**Блоки наезжают друг на друга.**
Расталкивание работает по 80 итераций с зазором 16 px. Если тесно — увеличьте `padding` в вызове `resolveOverlaps(boxes, 80, 16)`. Также можно уменьшить размеры шрифтов для отдельных типов через панель настроек.

**Как добавить свою карту?**
Положите `<имя>.json` в папку `roadmaps/` и добавьте запись в `manifest.json`:
```json
{ "file": "my-custom.json", "title": "My Custom Roadmap", "type": "role" }
```

**Прогресс пропал после перезагрузки.**
Проверьте, что браузер не в режиме инкогнито и не блокирует localStorage.

**Кнопки `✓` / `⏳` / `📝` / `🔍` перекрываются с блоками.**
Они рисуются чуть выше верхней грани блока. При расталкивании учитывается запас `BUTTON_HALO = 26px`. Если нужно больше места — увеличьте константу в начале скрипта.
