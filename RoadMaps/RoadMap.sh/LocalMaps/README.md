# 🗺️ Roadmap Viewer — локальный просмотрщик дорожных карт roadmap.sh

Интерактивный одностраничный просмотрщик дорожных карт с сайта [roadmap.sh](https://roadmap.sh). Работает **полностью локально**, без интернета и внешних зависимостей. Позволяет отмечать пройденные шаги, настраивать шрифт для каждого типа блоков и сохранять прогресс в браузере.

---

## ✨ Возможности

- **Полностью автономная работа** — никаких CDN, внешних библиотек, сетевых запросов (кроме загрузки JSON-файлов карт).
- **Все элементы дорожной карты** отрисовываются корректно: узлы, связи, типы блоков (`topic`, `subtopic`, `section`, `checklist`, `title`, `paragraph`, `button`).
- **Отметка прогресса** — клик по блоку или по кнопке `✓` помечает элемент как пройденный (серый фон + зачёркнутый текст). Повторный клик возвращает обратно.
- **Кнопка `🔍` Google-поиск** — открывает Google с запросом `<Название карты>: <текст блока>`. Например: `Redis: Using Package Managers`.
- **Прогресс сохраняется автоматически** в `localStorage`, отдельно для каждой карты.
- **Настройка шрифта по типам блоков** — размер, цвет и гарнитуру можно задать индивидуально для `topic`, `subtopic`, `section`, `checklist`, `title`, `paragraph`, `button` и `default`.
- **Умная раскладка**:
  - При увеличении шрифта блок **сначала** пытается уместить текст переносом строк.
  - Если текст не влезает — блок **растёт**, а соседние блоки **раздвигаются** (без перекрытий).
  - Связи между блоками автоматически перерисовываются.
- **Масштабирование и панорамирование** — колесо мыши, перетаскивание, двойной клик для «вписать карту».
- **Быстрое меню** со списком доступных карт, поиском по названию.
- **Современный вид** — карточки с мягкими тенями, скруглением, аккуратной цветовой схемой.

## 📂 Структура проекта

```
your-folder/
├── index.html              ← сам просмотрщик (открывается в браузере)
├── create-roadmaps.bat     ← создаёт папку roadmaps/ и пустые JSON + manifest.json
├── download-roadmaps.bat   ← (опционально) сразу скачивает JSON с roadmap.sh
└── roadmaps/               ← папка с JSON-файлами карт
    ├── manifest.json       ← список карт (генерируется .bat-файлом)
    ├── machine-learning.json
    ├── redis.json
    ├── postgresql-dba.json
    ├── ...
```

## 🚀 Быстрый старт

### 1. Скачайте или склонируйте файлы

Создайте пустую папку и положите туда `index.html` и `create-roadmaps.bat`.

### 2. Создайте папку `roadmaps` со списком карт

Двойной клик по **`create-roadmaps.bat`** — рядом появится папка `roadmaps/` с пустыми JSON-файлами и `manifest.json`.

> Если Windows блокирует запуск `.bat`: правой кнопкой → «Свойства» → «Разблокировать», либо запустите от имени администратора.

### 3. Заполните JSON-файлы данными

Откройте любую карту с roadmap.sh и сохраните её JSON по адресу `https://roadmap.sh/<slug>.json`.

**Примеры прямых ссылок:**

| Карта | JSON URL |
|---|---|
| Machine Learning | `https://roadmap.sh/machine-learning.json` |
| PostgreSQL DBA | `https://roadmap.sh/postgresql-dba.json` |
| Redis | `https://roadmap.sh/redis.json` |
| MongoDB | `https://roadmap.sh/mongodb.json` |
| Elasticsearch | `https://roadmap.sh/elasticsearch.json` |
| TypeScript | `https://roadmap.sh/typescript.json` |
| Python | `https://roadmap.sh/python.json` |
| SQL | `https://roadmap.sh/sql.json` |
| AWS | `https://roadmap.sh/aws.json` |
| Backend | `https://roadmap.sh/backend.json` |
| AI Engineer | `https://roadmap.sh/ai-engineer.json` |
| Code Review | `https://roadmap.sh/code-review-best-practices.json` |
| Backend Performance | `https://roadmap.sh/backend-performance-best-practices.json` |
| API Security | `https://roadmap.sh/api-security-best-practices.json` |
| Frontend Performance | `https://roadmap.sh/frontend-performance-best-practices.json` |

**Быстрый способ** — используйте `download-roadmaps.bat` (если добавили его): он сам скачает JSON для всех стандартных карт через `curl`.

> ⚠️ Кастомные ИИ-карты (например, `c-sharp-he09r` или `ml-engineer-3dqvu`) **не имеют публичного JSON** — они генерируются динамически. Для таких карт можно либо скрапить HTML, либо создать JSON вручную.

### 4. Запустите локальный сервер

Из-за политики CORS браузер не позволит прочитать `manifest.json` через `file://`. Запустите любой локальный HTTP-сервер из папки с `index.html`:

**Python 3:**
```bash
python -m http.server 8000
```

**Node.js (если установлен):**
```bash
npx serve
```

**PHP:**
```bash
php -S localhost:8000
```

### 5. Откройте в браузере

```
http://localhost:8000/index.html
```

Слева сверху появится меню `📚 Карты` — разверните его и выберите нужную карту. Либо вставьте URL JSON прямо в поле на стартовом экране и нажмите **Загрузить по URL**.

| Действие | Как |
|---|---|

| Сброс прогресса карты | Кнопка в панели настроек шрифта |
| Свернуть/развернуть панель | Клик по заголовку панели |

## ⚙️ Настройки шрифта

В панели `⚙️ Настройки шрифта` выберите **тип блока** (`topic`, `subtopic`, `section`, `checklist`, `title`, `paragraph`, `button`, `default`) и задайте для него:

- **Размер** — от 6 до 40 px.
- **Цвет** — любой через color picker.
- **Шрифт** — системный, Inter, Arial, Georgia, Consolas и др.

Настройки сохраняются в `localStorage` и восстанавливаются при следующем открытии.

При увеличении шрифта блок сначала пытается вместить текст переносом строк, и только если это не помогает — растёт. Соседние блоки автоматически раздвигаются, чтобы избежать перекрытий.

## 💾 Хранение данных

Все данные хранятся **только в вашем браузере** через `localStorage`:

| Ключ | Что хранит |
|---|---|
| `roadmap-progress-v2::<имя-карты>.json` | Прогресс по конкретной карте |
| `roadmap-font-settings-v2` | Настройки шрифта по типам блоков |

Чтобы сбросить всё — очистите данные сайта в браузере (DevTools → Application → Local Storage), либо используйте кнопки сброса в интерфейсе.

## ❓ Частые вопросы

**Меню `📚 Карты` пишет «manifest.json не найден».**
Откройте страницу **через локальный сервер** (`http://localhost:8000/...`), а не двойным кликом по `index.html`. Или убедитесь, что `create-roadmaps.bat` был запущен и `roadmaps/manifest.json` существует.

**Карта пустая, хотя JSON скачан.**
Проверьте, что в JSON есть поля `nodes` с `position.x/y` и непустым `data.label`. Служебные узлы (`horizontal node`, `vertical node`, пустые `section`) отфильтровываются автоматически.

**Как добавить свою карту?**
Положите `<имя>.json` в папку `roadmaps/` и добавьте запись в `manifest.json`:
```json
{ "file": "my-custom.json", "title": "My Custom Roadmap" }
```

**Прогресс пропал после перезагрузки.**
Проверьте, что в браузере не отключено сохранение данных сайта (например, режим инкогнито или блокировка cookies/localStorage).

**Кнопки `✓` и `🔍` перекрываются с блоками.**
Они рисуются чуть выше верхней грани блока и учитываются при расталкивании (запас 24 px). Если нужно больше места — увеличьте константу `BUTTON_HALO` в начале скрипта.
