**GraphRAG** — это исследовательский проект Microsoft, представляющий собой модульную систему **Retrieval-Augmented Generation (RAG) на основе графов**. В отличие от классического RAG, который ищет ответы в текстовых фрагментах, GraphRAG извлекает из неструктурированного текста **граф знаний**, строит иерархию сообществ и генерирует их сводки, используя эти структуры для выполнения RAG-задач.

### 🔍 Как это работает

Процесс GraphRAG включает несколько ключевых этапов:

1. **Индексация**: входной корпус разбивается на **TextUnits** (анализируемые единицы), из которых извлекаются все сущности, связи и ключевые утверждения.
2. **Кластеризация**: выполняется иерархическая кластеризация графа с использованием **метода Leiden** — каждый круг на графе представляет сущность (человека, место, организацию), размер отражает её степень, а цвет — сообщество.
3. **Суммаризация**: для каждого сообщества и его составляющих генерируются сводки снизу вверх, что помогает целостно понимать семантические концепции.

### 🆚 Отличие от Baseline RAG

Обычный RAG (Baseline RAG) использует векторный поиск по текстовым фрагментам и плохо справляется с двумя типами задач:

* **Связывание разрозненной информации**: когда для ответа нужно пройти по разным частям данных через общие атрибуты.
* **Целостное понимание**: когда требуется обобщить семантические концепции по большой коллекции документов.

GraphRAG решает эти проблемы за счёт графа знаний, что даёт **существенное улучшение** в ответах на вопросы, требующие рассуждений о сложной информации.

### 📌 Статус проекта

Проект находится в **режиме поддержки**: новые функции и PR не принимаются, но исправления ошибок и обновления зависимостей выполняются. Это **демонстрационный код**, а не официально поддерживаемый продукт Microsoft.

⚠️ **Важно**: индексация GraphRAG может быть **дорогостоящей операцией** — рекомендуется начинать с малых объёмов и внимательно изучить документацию.
