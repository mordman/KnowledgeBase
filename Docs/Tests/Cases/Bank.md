### Как импортировать

- **TestRail**: `Administration → Data Import → CSV` — сопоставьте колонки `Title → Title`, `Preconditions → Preconditions`, `Steps → Steps`, `ExpectedResult → Expected Result`, `Priority`, `Type → Type`, `Status → Status`.
- **TestLink**: `Test Project → Import → CSV` — используйте разделитель `,` и кодировку UTF-8; для многострочных полей замените переводы строк на `\n` при необходимости.
- **Jira/Xray/Zephyr**: используйте тот же CSV, замапив `ID → Test Key`, `Steps → Test Steps`, `ExpectedResult → Expected Result`.

Если нужно — могу дополнительно: разбить шаги на отдельные строки (step-by-step формат TestRail), добавить колонки `Owner`, `Sprint`, `Environment`, либо сгенерировать версию на 100 кейсов с покрытием конкретных банковских продуктов (ипотека, карты, кредиты).
