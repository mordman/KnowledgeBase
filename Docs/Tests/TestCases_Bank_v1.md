## Часть 3. Step-by-step формат (TestRail `steps_separated`)

В TestRail шаги можно импортировать **двумя способами**:
- **`Steps` — одной строкой** (как выше).
- **`Steps (step, expected per step)`** — каждая строка `Шаг -> Ожидаемый результат` соответствует одной ячейке таблицы шагов.

Формат CSV для step-by-step: `ID,Title,Step,Expected` — по одной строке на каждый шаг. TestRail объединяет строки с одинаковым ID.

### Пример: 10 кейсов в step-by-step

## Часть 4. Инструкции по импорту

**TestRail**
1. `Administration → Data Import → CSV`.
2. Маппинг: `Title → Title`, `Preconditions → Preconditions`, `Steps → Steps`, `ExpectedResult → Expected Result`, `Priority → Priority`, `Type → Type`, `Status → Status`, `Owner → Assigned To`, `Sprint → Milestone`, `Environment → Custom field`.
3. Для step-by-step импорта используйте **второй CSV**: `Administration → Data Import → CSV (Steps)`, маппинг `Step → Steps` (step), `Expected → Steps` (expected).

**TestLink**
- `Test Project → Import → CSV`; разделитель `,`, кодировка UTF-8. Для многострочных полей используйте `\n` внутри ячеек.
- Шаги TestLink поддерживает только одной строкой; step-by-step делается через `Test Steps` вручную или через API.

**Jira/Xray**
- Xray: `Test Management → Import → CSV`; маппинг `Steps` → `Test Steps` (формат `action|data|result`), `ExpectedResult` → `Expected Result`.

**Zephyr Scale**
- `Test Cases → Import → CSV`; шаги маппятся автоматически при разделителе `\n` в поле Steps.
